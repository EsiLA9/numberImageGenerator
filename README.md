# 序号图片生成器

一个面向 GitHub Pages 的纯前端图片工具：上传背景图片，拖拽序号到目标位置，并批量导出 PNG。项目内置方正兰亭圆简体字体，可在字体下拉菜单中选择。

## 本地预览

直接打开 `index.html` 即可使用。批量 ZIP 导出依赖浏览器加载 jsDelivr 上的 JSZip；如果网络不可用，单张 PNG 导出仍可使用。

也可以在本目录启动任意静态文件服务器后访问 `index.html`。

## 使用方式

1. 上传背景图片。
2. 设置起始序号、结束序号和补零位数。
3. 修改字体、字号、颜色、粗体、描边和透明度。
4. 在右侧预览画布中直接拖拽序号。
5. 下载当前 PNG，或点击“批量生成 ZIP”。

导出尺寸始终使用背景图原始尺寸，字号和位置按原图比例计算。

## 部署

将本目录内容提交到 GitHub 仓库，并在仓库设置中启用 GitHub Pages。项目没有后端服务，不需要数据库或环境变量。

字体文件 `方正兰亭圆简体 中.TTF` 会随网页由浏览器加载。公开部署前请确认该字体的网页嵌入和分发许可符合使用场景；如许可不允许公开分发，应改用已获授权的 WebFont 或系统字体。
